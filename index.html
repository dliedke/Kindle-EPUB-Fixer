What Kindle EPUB Fix does

Send to Kindle rejects EPUB files without ever saying why. The cause is almost always structural: a mimetype stored in the wrong place, a broken OPF manifest, internal links pointing to files that no longer exist, or a table of contents Kindle cannot read. Kindle EPUB Fix opens the book, lists every problem it finds, and rebuilds the package so Amazon accepts it.

Your book never leaves your computer. There is no server, no upload, and no account: the entire repair runs inside this browser tab, and the corrected EPUB is saved straight back to your device. It is free and works with any EPUB, including books exported from another app.

Full diagnosis before anything changes

Every issue is listed with its severity and the file it came from, plus a compatibility score from 0 to 100. You see exactly what was wrong and what was repaired.

Package and structure repair

Rebuilds the ZIP with the mimetype first and uncompressed, fixes the OPF manifest and spine, restores missing IDs and media types, normalizes file paths, and removes junk left behind by macOS, Windows, and editing tools.

Rebuilt table of contents

Finds chapters that exist in the book but are missing from the table of contents, regenerates the NAV and NCX navigation, and splits very long chapters into navigable parts using the book's own scene breaks.

Adjustable margins with live preview

Shrink or nearly eliminate the side margins to fit more text on an e-ink screen. The built-in preview renders real chapters, so you can compare against the original before repairing anything.

Batch mode for several books

Queue as many EPUB files as you need. Each file keeps its own repair options, and the whole queue can be downloaded as a single ZIP when it finishes.

Detailed downloadable report

Save the complete diagnosis as a JSON file in the language you selected, as a record of what changed in each book. Covers, DRM, and remote resources are all reported.
